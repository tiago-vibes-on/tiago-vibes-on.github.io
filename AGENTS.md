# Tiago VibesOn site instructions

- Use English for all content, code, and documentation.
- Keep the site simple and minimalist. Prefer clear typography, whitespace, and direct navigation over visual effects, large hero sections, decorative images, or card-heavy layouts.
- The homepage is the project index. Do not create a separate listing page while the homepage can show every project.
- Keep one page per project under `/projects/<project-slug>`.
- Keep `Tiago VibesOn` and `HandsOn` as the public brand spelling. Use lowercase, hyphenated names only for URLs, folders, and repository names.
- Add project content as Markdown in `src/content/projects` and link to the source in the `hands-on` repository rather than duplicating source code.
- Run `npm run build` after site changes.
